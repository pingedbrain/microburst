# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, be constructive, assume good intent. Harassment of any
kind is not tolerated.

Report unacceptable behavior to licha.pintos@gmail.com. Reports are handled
confidentially.
