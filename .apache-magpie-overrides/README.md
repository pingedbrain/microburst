# .apache-magpie-overrides/

Project-level overrides for [Apache Magpie](https://magpie.apache.org/)
skills. A file named `<skill>.md` here is read by that skill at run time,
before its default behaviour — this is how the project customizes a
framework skill without forking the framework.

Contract: https://magpie.apache.org/docs/setup/agentic-overrides

This repo adopts Magpie (see `/.apache-magpie.lock`). The committed floor is
deliberately minimal; install extra families per machine as needed.
